# Udemy Dual Subtitles

Chrome 내장 번역기로 Udemy 영어 자막 아래에 한국어 번역을 표시합니다. 영어 자막이 있는 강의에서 사용하세요.

1. Chrome 138 이상에서 `chrome://extensions`를 열고 개발자 모드를 켭니다.
2. **압축해제된 확장 프로그램을 로드합니다**를 눌러 manifest.json이 있는 폴더를 선택합니다.
3. Udemy 강의 페이지를 새로고침하고 영어 CC를 선택한 뒤 **이중 자막 시작**을 누릅니다. 처음에는 번역 모델 다운로드가 필요할 수 있습니다.

Udemy 플레이어의 전체화면을 지원합니다. video 요소만 전체화면으로 표시하는 경우에는 기본 자막을 사용합니다. 기존 한국어 자막 확장과 함께 설치했다면 기존 확장의 자막을 꺼 주세요.
